# 01 — Обзор проекта

## Что это

`ai-first-steps` — две анимированные видеопрезентации для 5–8 классов (11–14 лет) про ИИ. Сделаны на одном движке, но с разным стилем и темой.

| Презентация | Тема | Сцен | Хроно | Стиль | Ветка |
|---|---|---|---|---|---|
| **«Первые шаги в ИИ»** (оригинал) | Что такое ИИ, модель, ChatGPT vs Алиса vs GigaChat, как рисует/звучит | 30 `S0_1…S8_2` | 11:45 | Flat 2D, тёмно-синий `#1B2A4A`, вектор | `main` |
| **«Зачем ИИ школьнику»** (Pixar) | 4 суперсилы ИИ для школьника: репетитор, творец, исследователь, профессия будущего | 25 `PS0_1…PS8_2` | **6:19 / 379с** (растягивался до 11:00 с паузами) | Pixar 3D: тёплый `#FFF6E0`, объём, тени, блики, карточки | `arena/750486c0-ai-first-steps` |

Обе имеют: озвучку двумя голосами (Бит — мужской, Маша — девочка), вшитые субтитры, фоновую музыку с дакингом, раскадровку PDF, сценарий DOCX/MD.

## Педагогический принцип

Одна идея — одна сцена — одна метафора. После каждого блока чек-вопрос (зритель отвечает про себя). Никаких терминов без объяснения в момент появления.

## Кому подходит

* Учителям информатики/классным руководителям для урока 45 мин (видео 6-12 мин + обсуждение)
* Школьникам для самостоятельного просмотра
* Методистам как шаблон для своих тем (меняешь `lines.json` → получаешь новое видео)

## Системные требования

* **Разработка:** Windows 10/11, macOS, Ubuntu — Node 20 LTS, Python 3.11, 8ГБ RAM
* **Рендер Remotion:** 8 ядер / 16 потоков → 45-70 мин 1080p, 20-30 мин 720p, 2-3 ГБ на диске, Chrome Headless качается сам
* **Рендер FFmpeg:** те же 8 ядер → **3-5 мин 1080p**, 1 мин 720p, без Chrome, только Pillow+MoviePy
* **Просмотр:** любой плеер (VLC, MPC), проектор 1280×720+
