# 09 — Мультфильм с персонажами (character mode)

Новый тракт FFmpeg-рендера: вместо слайда «карточка + буква Б/М» ролик собирается как
мультфильм — **два постоянных персонажа на пер-сценных фонах**, с камерой, эмоциями и караоке.

```
assets/pixar/scene_<scene>.jpg   25 фонов 1920x1080
assets/pixar/bit*.png            Бит   (400x400 PNG, прозрачный фон)
assets/pixar/masha*.png          Маша  (400x400 PNG, прозрачный фон)
tools/pixar_frame.py             FrameRenderer — рисует один кадр
tools/build_ffmpeg_video.py      собирает кадры + звук -> mp4
```

## Персонажи

| Кто | Файлы | Характер в кадре |
|---|---|---|
| **Бит** (`b`) — робот-наставник | `bit.png`, `bit_surprised.png`, `bit_happy.png` | левитирует и покачивается сильнее (амплитуда 9px), стоит слева, ореол бирюзовый |
| **Маша** (`m`) — школьница 13 лет | `masha.png`, `masha_surprised.png`, `masha_happy.png` | дышит спокойнее (4px), стоит справа, ореол коралловый |

Правила отрисовки (`FrameRenderer._draw_characters`):

* **говорящий** — масштаб `1.00`, подъём `-12px`, пульсирующий ореол цвета персонажа, лёгкая «жестикуляция»;
* **слушающий** — масштаб `0.90`, яркость `0.68`, насыщенность `0.75`, альфа `0.88`;
* у ног — мягкая эллиптическая тень (привязывает фигуру к полу);
* смена эмоции: `neutral` (по умолчанию), `surprised`, `happy`.

Эмоции выбираются эвристикой по тексту реплики (`emotion_for` в `tools/pixar_frame.py`):
«за десять», «вау», «?!» → удивление; «поехали», «точно», «!»×2 → радость.
Хочешь задать вручную — положи `assets/pixar/emotions.json`:

```json
{ "За десять?!": "surprised", "Сделай своего — теперь ты знаешь как. Поехали!": "happy" }
```

## Фоны сцен

Приоритет: `assets/pixar/scene_<scene>.jpg` → пул `bgpool_*.jpg` + проекция сцены → градиент.

Пул (`bgpool_1_room` … `bgpool_5_workshop`) — базовые Pixar-планы. Их же использует
`tools/make_scene_backgrounds.py`, который делает **25 уникальных фонов**: свой кроп
(зум 1.24–1.58, своё смещение), свой грейд по блоку сценария, световое пятно/дымка,
винетка и затемнение под карточку.

```bash
python tools/make_scene_backgrounds.py --list    # что из чего собирается
python tools/make_scene_backgrounds.py --force   # перегенерировать все 25
```

Свой фон для сцены: положи `assets/pixar/scene_4.3.jpg` 1920×1080 — подхватится автоматом
и `make_scene_backgrounds.py` его не тронет (без `--force`).

Настроение блоков (`BLOCK_LOOK` в `pixar_frame.py`) — тон, сила, размытие, зум:

| Блок | Тема | Тон | Сила |
|---|---|---|---|
| 0 | ночная спальня / заставка | `#1A2340` | 0.30 |
| 1 | школа и репетитор | `#3C2A10` | 0.20 |
| 2 | мастерская идей | `#2A1040` | 0.26 |
| 3 | чек-вопрос | `#0E2A4A` | 0.30 |
| 4 | лаборатория | `#0C2E28` | 0.26 |
| 5 | город будущего | `#3A1A22` | 0.26 |
| 6 | осторожно, галлюцинации | `#301018` | 0.30 |
| 7 | чек-вопрос 2 | `#161E44` | 0.30 |
| 8 | финал, челлендж | `#3A2C0A` | 0.22 |

## Анимация

* **карточка реплики** — пружина `spring_value(damping=13, stiffness=140)`: подъезд снизу 70px,
  scale `0.94→1.00`, прозрачность; чип имени цвета спикера; акцентная полоска сверху.
* **караоке** — слово за словом `#FFD23F` + свечение, маркер-подчёркивание под текущим словом
  (доля прогресса = кадр / кадров в реплике).
* **камера** — фон рендерится с запасом 1.06 и медленно панорамируется (периоды 26с и 19с,
  фаза от номера сцены) — кадр «дышит», паузы не выглядят статичными.
* **титул сцены** — пилюля сверху + счётчик `N/25`; **прогресс** — полоска по всему ролику внизу.
* паузы (`gap`) — персонажи стоят спокойно, без карточки, камера продолжает движение.

## Рендер

```bash
# быстрый тест 2 реплики, 12.6с
python tools/build_ffmpeg_video.py --only 2 --motion 3 \
    --output preview/pixar-char-test-12s.mp4 --preset ultrafast --crf 26

# финал 379с 11370 кадров
python tools/build_ffmpeg_video.py --motion 3 --workers 2 \
    --output release/pixar-why-ai-characters.mp4 --crf 18 --preset medium --concurrency 2
```

Замеры (Debian 12, 2 vCPU, без GPU):

| режим | кадры | время | итог |
|---|---|---|---|
| 1 кадр, средний | — | 0.15с (первый в сцене 0.33с) | — |
| `--only 2` (378 кадров) | 378 | ~1 мин | 3.9МБ crf26 |
| full, `--workers 1` | 11370 | ~29 мин | — |
| full, `--workers 2` | 11370 | **13 мин** | 154МБ, crf18 medium |

`--workers N` — многопроцессная отрисовка сегментов (каждый процесс со своим рендерером,
кадры пишутся по глобальному индексу). На Windows работает через `spawn`, поэтому функции
воркеров лежат на уровне модуля.

## Отладка одного кадра

```bash
python tools/pixar_frame.py --scene 1.1 --who b --karaoke 0.55 --out /tmp/frame.png
python tools/pixar_frame.py --scene 5.1 --who m --no-sprites --out /tmp/bg_only.png
```

## Флаги, которые важно знать

| Флаг | Что делает |
|---|---|
| `--motion 3` | покадровая отрисовка (обязательна для персонажей) |
| `--legacy-flat` | старый режим: только карточка на общем фоне, без персонажей |
| `--no-sprites` | персонажи выключены (фон + карточка) |
| `--scene-dir` | папка с `scene_*.jpg` и спрайтами (по умолчанию `assets/pixar`) |
| `--workers N` | процессов отрисовки (1 = один поток) |
| `--only N` | первые N реплик (быстрый тест) |

## Звук

Берётся тот же `voice_track-pixar.mp3` (57 реплик, два голоса) + SFX + музыка:

* `pop.mp3` на старте каждой реплики ×0.7;
* `hiss.mp3` на сцене 2.2 (диффузия) ×0.25;
* `music_loop.mp3` в петлю, `volume=0.15` (ducking под голос);
* всё сводится `amix=inputs=3:duration=longest:normalize=0,alimiter=limit=0.95` и кодируется `aac`.

> `normalize=0` обязателен: по умолчанию `amix` делит громкость на число входов,
> и голос просаживается почти на 10дБ. Если правишь фильтр — проверь `volumedetect`.```

Голос не пере-таймируется: `timing-pixar.json` содержит абсолютные `start/end` каждой реплики,
поэтому карточки и караоке всегда совпадают с озвучкой.

## Что менять для новой темы

```bash
python tools/new_topic.py "Зачем нужна физика в 7 классе" --scenes 5
# -> script/lines_zachem-nuzhna-fizika-v-7-klasse.json
# записать озвучку в assets/audio/voice-<slug>/
python tools/build_pixar_real_timeline.py --lines script/lines_*.json \
    --voice assets/audio/voice-<slug> --out remotion/public/timing-<slug>.json
# фоны: assets/pixar/scene_<scene>.jpg  или  bgpool_* + make_scene_backgrounds.py
python tools/build_ffmpeg_video.py --motion 3 --workers 2 --output release/<slug>.mp4
```

Спрайты персонажей общие — они не привязаны к теме.
