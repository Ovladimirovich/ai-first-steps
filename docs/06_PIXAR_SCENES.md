## Тайминг 379.0с 57 реплик

* `script/lines_pixar_why_ai.json` — 57 реплик `p<блок>_<сцена>_<b|m>_<n>` (Бит/Маша)
* `assets/audio/voice-pixar/p0_1_m_01.mp3 … p8_2_b_03.mp3` — 57 mp3 1.4МБ (voice-00/01 + `build_pixar_real_timeline.py` склейка)
* `remotion/public/timing-pixar.json` — 379.0с, 71 cue → реально 57 `lines` + `cues` (разбивка длинных фраз по пунктуации)
* `subtitles/ru-pixar.srt` — 8.5К
* `remotion/public/audio/voice_track-pixar.mp3` — 2.9МБ mono 48kHz

Пример cue:
```json
{"id":"p1_2_b_02","scene":"1.2","who":"b","text":"Вот фишка — попроси ИИ объяснить как для друга...","start":49.56,"end":57.86,"dur":8.3}
```

Гэпы между `end` и следующим `start` — паузы 0.3-0.6с (в FFmpeg — `gap` сегмент с фоном без карточки, в Remotion — просто держит кадр).

## Визуал Pixar (что отличает от оригинала)

* **Палитра** `remotion/src/pixarTheme.ts`: `bg #FFF6E0` тёплый вместо `#1B2A4A`, акценты `teal #2EE6D6 / yellow #FFD23F / coral #FF6B6B`
* **PixarCard** `components/PixarCard.tsx`: `width 1400`, `borderRadius 28`, `boxShadow 0 20px 60px + inset блик + inset тень`, `spring dirty 13/140`, `translateY 36px → scale 0.92→1`, `font Montserrat 40px`
* **Персонажи** `PixarCharacters.tsx`: Бит — бирюзовый кубик с градиентом/SSS, Маша — худи/рюкзак, планшет
* **Фоны** `assets/pixar/clouds_pixar_bg.jpg` 86К, `classroom_pixar.jpg` 274К (AI-концепт), подмешиваются 0.18 в FFmpeg
* **Сцены** `pixarScenes/PS*.tsx` — 25 файлов 1.4-5Кб каждый, копируй `PS1_2` как шаблон для новых

## Как добавить сцену

1. Скопируй `PS1_2.tsx` → `PS9_1.tsx`, поменяй `scene="9.1"` и текст, используй `<PixarCard>`, `<PixarHL>`, `<PixarTitle light>`
2. Добавь реплики в `script/lines_pixar_why_ai.json` + запиши `assets/audio/voice-pixar/p9_1_*.mp3`
3. `python tools/build_pixar_real_timeline.py` → `timing-pixar.json` + `voice_track-pixar.mp3`
4. `npm run dev` → `PixarWhyAI` → проверь, затем `python tools/build_ffmpeg_video.py` или `npx remotion render`
