# Запуск AI Video Factory

Приложение запускается локально на вашем компьютере и сохраняет проекты в `.factory/`. Для разработчиков: [F3 actions/queue и F4 review flow](f3-action-queue.md), [F5 visual prompts/variant history](f5-visual-variants.md).

## Первый запуск

1. Установите Python 3.10 или новее.
2. Откройте терминал в корне репозитория.
3. Создайте окружение и поставьте зависимости:

   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # macOS / Linux: source .venv/bin/activate
   python -m pip install -r requirements-factory.txt
   ```

4. На своём Windows-компьютере запустите мастерскую только для этого компьютера:

   ```bash
   python -m factory --host 127.0.0.1
   ```

5. Откройте `http://localhost:7860`.

В Windows можно запустить `run.bat` из любой папки: он использует корень репозитория, предпочитает `.venv` и слушает только `127.0.0.1`; для остановки запустите `stop.bat`. Остановка проверяет сохранённый PID и команду процесса, не завершает другие Python-программы. В Arena-предпросмотре используйте `python -m factory` (он слушает `0.0.0.0`). Для llama.cpp и личных проектов запускайте приложение локально с `--host 127.0.0.1`.

## Подключение локального llama.cpp

Если ваш `llama-server` уже запущен на этом же компьютере, откройте шаг «Замысел» → «Помощник для сценария», выберите локальный вариант и укажите `http://127.0.0.1:8081/v1`. Кнопка «Проверить помощника» проверит связь и автоматически сохранит первый точный ID из списка моделей; вручную копировать путь к GGUF не нужно. Генерация запрашивает JSON-режим llama.cpp, автоматически делает одну локальную попытку починить некорректный JSON и совместима со старыми сборками сервера, которые отклоняют `response_format`. Проверка обращается только к локальному адресу и не отправляет сценарии в облако. Генерация текста выполняется по одному запросу за раз.

Для связи с вашим Windows-сервером запустите саму фабрику **на Windows-компьютере**: предпросмотр Arena работает в отдельной песочнице и не может подключиться к `127.0.0.1` вашего ПК. Настройка хранится локально в `.factory/settings.json`; пароль и API-ключ не нужны.

## GigaChat

В «Помощнике для сценария» можно выбрать облачный GigaChat рядом с демо и локальным Qwen. Получите учётные данные API самостоятельно, затем в корне репозитория выполните `Copy-Item .env.example .env` и заполните в `.env` поля `GIGACHAT_CLIENT_ID` и `GIGACHAT_CLIENT_SECRET`. `.env` исключён из Git; не присылайте значения в чат. TLS-проверка включена. Интерфейс отдельно предупреждает, что тема и текст уйдут в облако и запрос может тарифицироваться; без явного согласия сценарий не отправляется. Кнопка проверки проверяет доступ к API, не генерируя текст. Запускайте фабрику на своём ПК, чтобы она прочитала ваш локальный `.env`.

## Демо-режим первой версии

- Черновик сценария формируется локальным шаблоном без внешних запросов.
- Голосовые MP3 — **тишина с рассчитанной длительностью**, а не синтезированная речь.
- Кадры рисуются кодом существующего рендерера; на шаге «Картинки» можно загрузить свой фон для отдельной сцены.
- MP4 собирается тем же рендерером по отдельным сегментам сцены. Сегмент меняется только при изменении его содержимого, а финальный файл быстро склеивается заново.
- Старые команды и входы рендерера по умолчанию сохранены; новые параметры необязательные.
- До запуска озвучки, подготовки кадров и сборки видео показывается смета и требуется явное подтверждение. В демо-режиме цена равна 0 ₽.

Все файлы проектов и готовые MP4 находятся в `.factory/projects/`. Папка исключена из Git. Не удаляйте её, если хотите сохранить свои ролики.
